RouteOpt

Intelligent Multi-Stop Delivery Route Optimization System

How It Works

RouteOpt solves the Capacitated Vehicle Routing Problem (CVRP), a complex NP-hard combinatorial optimization problem where a fleet of vehicles with capacity constraints must service a set of delivery demands from a central depot in the most cost-effective way.

1. OpenStreetMap Data Retrieval

When you input locations, the system sends coordinates to the OpenStreetMap Routing Machine (OSRM) Table API. OSRM calculates a real-world road-routing distance matrix and travel-duration matrix.

2. Google OR-Tools Engine

The distance matrix and stop demands are passed to Google OR-Tools. The solver uses advanced constraint programming heuristics (such as Guided Local Search) to find the globally optimal route paths in seconds, ensuring vehicle capacities are never exceeded.

3. Detailed Geometry Overlay

Once OR-Tools determines the node sequence for each vehicle, the backend queries the OSRM Route API to fetch the exact GeoJSON road path. The frontend then renders these colored lines matching street curves.

CVRP Formulation

Objective: Minimize Total Routing Cost

Min ∑ c_ij * x_ijv

Constraints:

  • Every customer is visited exactly once.
  • Every vehicle route starts and ends at the Depot.
  • Total demand of any route cannot exceed vehicle capacity: ∑ d_i * y_iv ≤ Q_v
