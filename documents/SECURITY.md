# Security Policy

## Supported Versions

Only the latest `main` branch of RouteOpt is actively maintained with security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within RouteOpt, please do not disclose it publicly in an open issue.

1. Send an email with details, proof-of-concept steps, and potential impact to the repository maintainer.
2. Alternatively, create a private security advisory on GitHub if enabled.
3. Maintainers will review the report within 48 hours and coordinate a fix prior to public disclosure.
